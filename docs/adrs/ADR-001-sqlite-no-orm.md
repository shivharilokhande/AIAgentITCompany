# ADR-001: SQLite via Node's built-in `node:sqlite`, no ORM
**Status:** Accepted (amended during Sprint 1) · **Context:** single-user self-hosted tool, ~10 tables. Prisma 7 requires driver adapters; `better-sqlite3` needs a native build (prebuilt download + node-gyp failed in the sandbox and is a common friction point on fresh Macs). **Decision:** use `node:sqlite` (`DatabaseSync`), loaded via `process.getBuiltinModule` so Next's bundler never touches it; idempotent `schema.sql`; typed repo layer. Requires Node ≥ 22.13. **Consequences:** zero native deps, `npm install` is pure JS, one-file backup; Node prints an ExperimentalWarning once at startup (harmless); schema changes are additive DDL guarded by `IF NOT EXISTS`.
